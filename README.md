# ccfe — Curses Command Front-End

ccfe supplies an interactive, screen-oriented (curses) interface to
command line scripts and commands, driven by simple menu and form
definition files.

Original author: Massimo Loschi <ccfedevel@gmail.com>.
License: GPL-2.0 (see `COPYING`).

This repository preserves the project after the original homepage
(http://ccfe.altervista.org) went offline. The `v1.58` tag is the
unmodified 1.58 release tarball; later commits contain fixes for
current systems. See `README` for the original documentation.

Requires Perl with the `Curses` module built with panels, menus and
forms support.
